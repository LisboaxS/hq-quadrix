# 📚 hq-quadrix - Meu projeto

> Uma plataforma interativa para leitura e apreciação de histórias em quadrinhos online.

O **hq-quadrix** é um projeto desenvolvido para oferecer uma experiência de leitura fluida, organizada e visualmente atraente para fãs de HQs. O site permite navegar por diferentes títulos, capítulos e gêneros de forma intuitiva.

---

## 🚀 Funcionalidades

*   **Leitor Responsivo:** Visualize quadrinhos perfeitamente no desktop ou celular.
*   **Biblioteca Organizada:** Filtros por gênero, autor e popularidade.
*   **Favoritos:** Salve suas HQs preferidas para ler mais tarde (necessário login).
*   **Dashboard Administrativo:** Interface para upload de novos capítulos e gerenciamento de conteúdo.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído com as seguintes ferramentas:

| Tecnologia | Finalidade |
| :--- | :--- |
| **HTML5/CSS3** | Estruturação e estilização da interface. |
| **JavaScript/React** | Lógica de navegação e interatividade do leitor. |
| **Node.js** | Ambiente de execução do backend (se aplicável). |
| **MySQL/MongoDB** | Armazenamento de dados das HQs e usuários. |
